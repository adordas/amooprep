# Adding future course packs

AmooPrep is the brand/engine. Each class becomes a course pack instead of a separate near-identical extension.

For each new course:
1. Give the pack a neutral subject title, not a school-branded title.
2. Create original/commercial-safe `questions`, `concepts`, `flashcards`, `timeline`, and `people` data.
3. Create a separate Lemon Squeezy product/variant and license key configuration for that pack.
4. Keep the same adaptive engine and interface.
5. Add the pack to a future Course Library screen.

This avoids publishing many duplicate Chrome extensions and allows one customer to own multiple course packs under the same AmooPrep product family.
