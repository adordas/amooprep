# Chrome Web Store checklist

## Developer account
- Register a Chrome Web Store developer account and pay Google's one-time registration fee.
- Use an email address you plan to keep long-term.
- Complete developer identity/contact information and 2-step verification as requested.

## Extension
- Manifest V3.
- Single purpose: adaptive pre-exam studying.
- Only `storage` permission plus Lemon Squeezy API host access.
- No browsing-history access, page injection, assessment scraping, or proctoring interaction.
- Payment disclosure must clearly say AmooPrep is the seller, not Google.
- Free-vs-Premium differences must be clear in the listing before installation.

## Public pages
Host these on a public HTTPS URL (GitHub Pages is a free option):
- Privacy policy
- Terms of sale/use
- Refund policy
- Support/contact page

## Listing
Use a neutral listing such as:
**AmooPrep — Adaptive Study Companion**

Do not use a university name, logo, course code, or wording that implies endorsement. Course packs should use subject names such as `Greek & Roman Civilization — Final Review`.
