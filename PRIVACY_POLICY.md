# AmooPrep Privacy Policy — Draft

**Last updated:** August 2026

AmooPrep is designed to minimize data collection.

## Data stored on the user's device
AmooPrep stores study progress, question statistics, mastery information, and Premium license state locally using Chrome's local extension storage. This data is used only to provide study features and remember Premium access on that browser profile.

## License activation
When a user chooses to activate Premium, AmooPrep sends the license key, a non-identifying browser-instance label, and the email entered by the user to Lemon Squeezy's license service over HTTPS. The email is compared with the purchase record for activation and is not intentionally saved by AmooPrep. AmooPrep stores the license key and Lemon Squeezy instance ID locally so the license can be validated later.

## Payments
Payments are completed on Lemon Squeezy's hosted checkout. AmooPrep does not receive or store credit-card numbers or full payment details. Lemon Squeezy processes checkout data under its own policies.

## Data AmooPrep does not collect
AmooPrep does not collect browsing history, course-site credentials, live exam content, proctoring data, advertising identifiers, or location data. The current version has no advertising analytics.
